# 주식 모닝브리핑 구독 서비스 - 기능 정의서 (MVP)

**작성일**: 2026.07.04  
**작성자**: Antigravity  

본 문서는 실데이터 기반 주식 모닝브리핑 구독 서비스의 **MVP(Minimum Viable Product, 최소 기능 제품)** 개발을 위한 핵심 기능 정의서입니다.

---

## 📌 1. MVP 핵심 기능 범위 요약

MVP 단계에서는 복잡한 기능은 제외하고, **"실데이터 수집 ➡️ 검증 ➡️ LLM 요약 ➡️ 카카오톡/이메일 발송"**의 핵심 가치 사슬을 검증하는 것에 집중합니다.

1. **사용자 관리**: 카카오 소셜 로그인 기반의 가입 및 구독 상태 관리
2. **관심종목 설정**: 유료 사용자의 개인화 브리핑을 위한 종목 등록/삭제 (최대 5개)
3. **데이터 수집 엔진**: KRX, KIS, DART, Yahoo Finance API 연동 및 DB 저장
4. **LLM 브리핑 생성 및 숫자 검증**: Claude API를 활용한 요약 및 데이터 불일치 검증 로직
5. **발송 엔진**: 이메일(SMTP) 및 카카오 알림톡(비즈엠 등 API 연동) 발송
6. **결제 및 빌링 (수동/자동)**: 아임포트/포트원 연동을 통한 정기 결제

---

## ⚙️ 2. 상세 기능 정의 (System Specification)

### 2.1 사용자 관리 및 구독 모델 (User Management)

#### F-101: 카카오 간편 로그인 및 가입
- **설명**: 한국 투자자의 접근성을 높이기 위해 카카오 소셜 로그인을 제공합니다.
- **동작 흐름**:
  1. 사용자가 웹사이트에서 `카카오로 시작하기` 버튼 클릭.
  2. 카카오 인증 후 회원 정보(카카오 ID, 이메일, 프로필 이름) 획득 및 회원가입 처리.
  3. 최초 가입 시 기본 구독 티어는 `무료(Free)`로 설정.

#### F-102: 구독 티어 관리
- **구독 등급**:
  - `Free` (무료): 공통 지수 요약 제공, 카카오톡 오픈채팅(공용) 또는 블로그 링크 확인 가능.
  - `Premium` (유료): 관심종목 요약 추가, 카카오 1:1 알림톡 또는 이메일 개인 발송 (07:30 발송).
- **데이터 필드**: 유저 테이블 내 `subscription_tier` (FREE / PREMIUM), `subscription_status` (ACTIVE / EXPIRED) 관리.

---

### 2.2 개인화 관심종목 설정 (My Portfolio) - *PREMIUM 전용*

#### F-201: 관심종목 검색 및 등록
- **설명**: 유료 구독자가 매일 아침 브리핑을 받고 싶은 종목을 설정하는 기능입니다.
- **상세 규격**:
  - 한국 주식(코스피/코스닥) 종목명 또는 종목코드(6자리) 검색 기능 제공.
  - 검색된 종목을 관심종목 리스트에 추가 (MVP 단계에서는 **최대 5개**로 제한).
  - 이미 등록된 종목은 중복 등록 불가 경고 노출.

#### F-202: 관심종목 삭제
- **설명**: 관심종목 목록에서 마이너스(-) 버튼 또는 삭제 아이콘 클릭 시 리스트에서 즉시 제거.

---

### 2.3 데이터 수집 스케줄러 (Data Batch Job)

#### F-301: 데일리 데이터 수집 스케줄러
- **설명**: 매일 아침 자동으로 주식 시장 관련 데이터를 수집하는 백엔드 배치 작업입니다.
- **실행 시간**: **매일 아침 06:40 ~ 07:00** 사이 실행 완료 목표.
- **수집 대상 데이터**:
  1. **해외 증시 (Yahoo Finance API)**: 다우, S&P500, 나스닥, 필라델피아 반도체 지수의 종가 및 등락률.
  2. **국내 증시 지표 (KIS/KRX API)**: 코스피, 코스닥 종가, 등락률, 총 거래대금.
  3. **시장 수급 (KIS/KRX API)**: 코스피/코스닥 개인, 기관, 외국인 매매동향(순매수 금액).
  4. **관심종목 시세 (KIS API)**: 프리미엄 구독자들이 등록한 관심종목의 전일 종가, 등락률, 거래량.
  5. **관심종목 공시 (DART API)**: 관심종목 관련 전일 발행된 주요 공시 정보(공시 제목, 링크).

---

### 2.4 LLM 브리핑 생성 및 숫자 검증 (AI & Validation)

#### F-401: Claude API 연동 브리핑 템플릿 생성
- **설명**: 수집된 정량 데이터를 가독성 좋은 자연어 코멘트로 변환합니다.
- **LLM 통제 규칙 (System Prompt)**:
  - > *"제공된 JSON 데이터에 있는 숫자와 텍스트만 기반으로 작성하라. 절대 데이터에 없는 정보를 지어내거나 추정(hallucination)하지 마라. 예를 들어, 코스피 지수가 2,500.50이라면 정확히 그 숫자를 써야 하며, 2,500으로 반올림하거나 다른 숫자를 지어내선 안 된다."*

#### F-402: 2단계 숫자 불일치 검증 (Double-Check Validator)
- **설명**: LLM이 숫자를 올바르게 요약했는지 검증하는 자체 알고리즘입니다.
- **동작 흐름**:
  1. Claude가 생성한 마크다운 텍스트를 입력값으로 받음.
  2. 텍스트 내에서 정규식을 이용해 모든 숫자(퍼센트, 금액, 지수 등)를 추출.
  3. 원본 API 수집 데이터(JSON)에 존재하는 숫자 집합과 대조.
  4. 만약 원본 데이터에 존재하지 않는 엉뚱한 숫자가 발견될 경우:
     - **1차 대응**: 프롬프트에 불일치 오류를 명시하여 Claude에게 재요청 (최대 2회).
     - **최종 실패 시**: 스케줄러 작동 중단 및 관리자에게 Slack/SMS로 긴급 알림 전송.

---

### 2.5 발송 엔진 (Delivery System)

#### F-501: 프리미엄 구독자 발송 (07:30)
- **이메일 발송**: HTML 템플릿 기반으로 작성된 개인화 브리핑 이메일을 AWS SES 또는 SMTP를 통해 발송.
- **카카오 알림톡 발송**: 비즈엠(Bizm) 등 알림톡 API 연동을 통해 구독자 휴대폰 번호로 발송. 
  - *참고*: 카카오톡 규정상 개인별 맞춤형 정보(보유종목 등)는 정보성 메시지에 해당하므로 알림톡 발송이 가능합니다.

#### F-502: 무료 구독자 발송 (08:30)
- **카카오톡 오픈채팅방 발송**: 봇(Bot)을 통해 특정 오픈채팅방에 공통 브리핑 텍스트 자동 전송.
- **네이버 블로그 포스팅**: 네이버 API를 통해 공통 브리핑 내용을 담은 글 자동 포스팅 발행.

## 🔒 3. 보안 및 규제 대응 요구사항 (Compliance)

#### F-601: 투자 정보 고지 및 면책 문구 자동 삽입
- **설명**: 모든 발송 메시지 및 블로그 포스팅 하단에 법적 면책 고지 문구를 필수로 포함합니다.
- **필수 삽입 문구 예시**:
  > *"본 정보는 KRX/DART/KIS API 등의 공식 데이터에 기반하여 제공되는 단순 정보성 서비스이며, 투자 권유나 특정 종목의 추천이 아닙니다. 모든 투자의 결정과 책임은 투자자 본인에게 있습니다."*
