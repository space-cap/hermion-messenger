# 실데이터 기반 주식 모닝브리핑 구독 서비스 기획서

**작성일**: 2026.07.01
**작성자**: 이영현

---

## 1. 서비스 개요

### 1.1 한 줄 정의
매일 아침, **검증된 실데이터(DART/키움 API)** 기반으로 생성되는 국내외 증시 브리핑을 카카오톡/이메일/네이버블로그로 구독자에게 발송하는 개인화 정보 서비스.

### 1.2 문제 정의
- 기존 ChatGPT/Gemini 스케줄러 기반 브리핑은 **환각(hallucination) 리스크**가 있음 — 실시간 거래대금, 수급 데이터, 종목 등을 LLM이 추정해서 생성함 (`(추정)` 태그가 이를 증명)
- 한국 개인투자자는 Slack/Discord를 쓰지 않음 — 카카오톡, 이메일, 네이버 기반 유통이 실질적
- 무료 정보는 넘치지만, **내 보유종목 기준으로 개인화된 브리핑**은 부족

### 1.3 핵심 차별점
| 구분 | 일반 AI 스케줄러 (ChatGPT/Antigravity) | 본 서비스 |
|---|---|---|
| 데이터 소스 | LLM 자체 브라우징/추정 | DART·키움 공식 API 실데이터 |
| 정확도 | 숫자 환각 가능 (`추정` 표기) | API 원본 데이터와 100% 일치 (검증 로직 포함) |
| 개인화 | 범용 요약 | 구독자 보유/관심 종목 기반 맞춤 브리핑 |
| 유통 채널 | Slack, Discord | 카카오톡, 이메일, 네이버블로그 (한국 투자자 실사용 채널) |
| LLM 역할 | 정보 생성 (숫자까지 창작) | 정리·해설만 담당 (숫자는 API가 제공) |

## 2. 타겟 고객

- **1차 타겟**: 국내주식 투자 개인투자자 중, 매일 아침 정보 확인은 하고 싶지만 시간이 부족한 직장인
- **2차 타겟**: 자동매매/퀀트 전략에 관심 있는 투자자 (원자재 데이터, 투자자별 매매동향 등 고급 데이터 수요)
- **특징**: 카카오톡 채널·네이버블로그 등 선생님이 이미 보유한 채널/팔로워를 초기 유입원으로 활용 가능

## 3. 요금제 (프리미엄 모델)

### 무료 티어
- 국내 지수(코스피/코스닥) 등락률 + 해외 3대 지수 요약
- 발송 채널: 카카오톡 오픈채팅 or 네이버블로그 (지연 발송, 예: 08:30)
- 목적: 유입 확대, 입소문, 유료 전환 퍼널

### 유료 티어 (예: 월 9,900원 ~ 19,900원 구간에서 시장 반응 보며 조정)
- 실시간 투자자별 매매동향(외국인/기관/개인 수급) 상세
- **개인화**: 구독자가 등록한 관심종목 기준 브리핑 섹션 추가
- DART 공시 자동 파싱 요약 (관심종목 관련 공시만 필터링)
- 발송 시간 우선순위 (예: 07:30 발송, 무료 티어보다 먼저)
- 카카오톡 1:1 알림톡 발송 (오픈채팅 아닌 개인 채널)

### 프리미엄/VIP 티어 (선택, 추후 확장)
- 정량 신호 결합 (RSI 등 기술적 지표 코멘트)
- 테마·수급 기반 스크리닝 리스트 (LLM 추론 아닌 실제 등락률 상위 스크리닝)
- 주간 리포트 PDF 추가 제공

> **가격은 초기엔 낮게(예: 9,900원) 시작해 구독자 반응 보고 조정 권장.** 유사 서비스(증권사 리서치 유료 구독, 텔레그램 유료방)가 보통 월 1~5만원대 형성.

## 4. 기술 아키텍처

```
[스케줄러: 매일 07:00]
   ↓
[데이터 수집 레이어]
   - 키움 REST API → 국내 지수, 투자자별 매매동향, 실시간 시세, 개인화 종목 조회
   - DART Open API → 공시 데이터
   - Yahoo Finance API → 해외지수(다우/S&P/나스닥/필라델피아반도체)
   ↓
[데이터 정제·검증 레이어]
   - JSON 구조화
   - 결측치/이상치 체크
   ↓
[LLM 레이어 - Claude API]
   - 역할: 데이터 요약·해설만 (숫자 생성 금지 시스템 프롬프트)
   - 구독자별 개인화 종목 섹션 별도 생성
   ↓
[검증 레이어]
   - 생성된 텍스트 내 숫자가 원본 API 데이터와 일치하는지 스크립트 검증
   - 불일치 시 재생성 or 알림
   ↓
[발송 레이어]
   - 무료 티어: 카카오톡 오픈채팅 / 네이버블로그
   - 유료 티어: 카카오 알림톡(개인) / 이메일
   ↓
[구독/결제 관리]
   - 토스페이먼츠 or 아임포트 연동
   - 구독자 DB (관심종목, 티어, 결제상태)
```

### 개발 우선순위
1. KRX/DART API 승인 완료 후 데이터 수집 스크립트 (Antigravity에서 작업)
2. Claude API 프롬프트 설계 (숫자 창작 방지 + 검증 로직)
3. 무료 티어 MVP → 카카오톡 오픈채팅 배포로 테스트
4. 결제 시스템 연동 + 유료 티어 개인화 기능
5. 검증/모니터링 자동화 (환각 발생 시 알림)

## 5. 수익 모델 및 목표 (예시 시나리오)

| 항목 | 3개월 목표 | 6개월 목표 |
|---|---|---|
| 무료 구독자 | 300명 | 1,000명 |
| 유료 전환율 | 3~5% | 5~8% |
| 유료 구독자 | 10~15명 | 50~80명 |
| 월 매출 (단가 9,900원 기준) | 10~15만원 | 50~80만원 |

> 초기엔 매출보다 **"실데이터 기반 = 신뢰"**라는 포지셔닝을 검증하고, 무료→유료 전환 퍼널이 작동하는지 확인하는 게 우선.

## 6. 리스크 및 대응

| 리스크 | 대응 방안 |
|---|---|
| KRX/DART API 승인 지연 | 승인 대기 중 파이프라인 뼈대 코드 미리 작성 |
| 유사투자자문업 규제 이슈 (투자 조언으로 오인 소지) | 브리핑은 "정보 제공"이며 "투자 조언 아님" 명시, 매수/매도 추천 문구 배제 |
| LLM 환각 재발 | 검증 스크립트로 숫자 불일치 자동 탐지, 실패 시 발송 중단 |
| 초기 구독자 확보 어려움 | 기존 네이버블로그/카카오톡 채널 팔로워 활용, 무료 티어로 입소문 유도 |
| 카카오 인프라 비용(알림톡 발신 단가) | 구독자 수 증가 전까지 이메일/오픈채팅 중심 운영 |
